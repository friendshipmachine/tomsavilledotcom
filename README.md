# Tom Saville portfolio

Current static portfolio is in `docs/`. Original Adobe capture is retained in `preservation/`.

## Publish
In Settings → Pages, select Deploy from a branch, main, /docs, and Save. GitHub Free requires a public repository.

The site uses relative links and works at the repository Pages URL or a custom domain. Videos load from Vimeo and YouTube. Epic Games / Fortnite is marked coming soon.
