# Tom Saville portfolio

Preserved from tomsaville.com on October 17, 2026.

The `docs` folder contains the portable website. In Settings → Pages, choose Deploy from a branch, main, /docs, then Save. Free GitHub Pages requires a public repository; private repository Pages availability depends on your GitHub plan.

The website preserves all ten sitemap pages, local images/styles, and 49 video embed placements (47 distinct video URLs). Videos remain hosted on Vimeo and YouTube. The archived Adobe contact form does not send messages. Original HTML and capture inventory are retained in `preservation`.

Links are relative so the site works at both the project Pages URL and a future custom domain. DNS has not been changed. Browser playback and visual layout are not yet verified.
